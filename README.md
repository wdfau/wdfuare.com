# 微光作品岛 · 治愈系 3D 空间

一座面向 UI/UX 求职展示的可探索小岛。当前交付是空间模型与交互原型，展板使用抽象界面，尚未接入真实个人资料、案例或简历。

## 运行

需要 Node.js 22.12+ 或兼容版本。

```sh
npm ci
npm run dev
```

`npm run check` 检查类型，`npm run build` 生成静态网页，`npm run preview` 预览构建。

## 空间规划

按招聘方了解一名设计实习候选人的顺序组织，常驻导航可直接前往任何区块。

| 区域 | 求职展示用途 | 空间中的物件 |
| --- | --- | --- |
| 入口导览 | 建立定位、说明从哪里开始 | 导览石、坐凳、通向展庭的主石径 |
| 作品展庭 | 承载完整案例、方案取舍和可运行原型 | 暖白石拱、双展板、手机原型台、木制展架 |
| 设计手作坊 | 呈现观察、草图和设计推敲过程 | 画架、卷纸、书本、材料板、工作桌、电脑和台灯 |
| 交互花园 | 让访客体验动效与前端细节 | 弹性球、转盘、拉杆三座装置与环形踏石 |
| 关于与联系 | 预留个人背景、简历和联系入口 | 书架、纸页板、信箱、坐凳与暖灯 |
| 休憩海岸 | 为探索提供停顿和收束 | 木栈道、临海坐凳、灯笼、小篝火 |

区域名称、用途与标记统一维护在 `src/scene/islandPlan.ts`。目前没有虚构的教育、履历、成果数字或联系方式。

## 风格与细节

草甸、弯干阔冠树、细叶草、花丛、蘑菇和苔石替代大面积冷灰铺装；建筑采用暖白石、浅木和少量柔和金色光。不同区块通过道具表达用途，而不是单纯增加装饰数量。

视觉参考《Sky: Children of the Light》的温暖、轻盈与自然氛围。原始参考为 [thatgamecompany 官方网站](https://www.thatskygame.com/) 和 [主美 Yuichiro Tanabe 的 GDC 美术分享](https://media.gdcvault.com/gdcsummer2020/presentations/Tanabe-Yuichiro-Art%20of%20Sky_%20Children%20of%20the%20Light.pdf)。模型、材质与界面均为本项目程序生成，无外部模型、贴图、字体或游戏素材下载。

水面通过多方向波的顶点起伏、连续变化的法线与天空/日光反射形成流动感；岸边泡沫限定在实际岛屿轮廓附近，不使用绘制短线作为水波纹理。

细节版补充了入口悬旗、调研桌、育苗台、卷纸架、香草摊、纸卡柜、伞下阅读角、野餐垫和风铃。建筑内部加入桌面工具、绘图纸、书本、灯具和收纳；树下有根系、鸟巢、蕨草、铃兰、雏菊、枯木、树桩和落叶，蝴蝶在花丛间轻轻飞动。码头加入绳结、船桨、木桶、救生圈和软梯，沙岸有贝壳、海星、漂流木和潮池。这些细节按材质与几何批量实例化绘制。

## 操作与动画

鼠标移动时全岛轻微随动；悬停建筑会有局部反馈。拖动旋转、滚轮缩放、右键平移，触摸设备使用单指旋转、双指缩放/平移。点击场景标记或左侧分区可自动抵达。

0–5 按分区编号切换视角，R / Escape 返回总览。支持材质/白模、自动旋转、网格和标记显示；标记是主 HTML 界面中的真实按钮，随 3D 投影更新位置，可用键盘访问。

系统减少动效时，程序相机动画、视差、悬浮、草木风动、海浪与自动旋转停止。页面隐藏时暂停渲染。动画在帧循环中更新，重复植物与道具采用实例化，不逐帧更新 React 状态。

## 项目文件

- `src/scene/IslandLandscape.tsx`：地形、树木、花草和各区域道具。
- `src/scene/IslandBuildings.tsx`：四处功能建筑与交互装置。
- `src/scene/IslandLife.tsx`：岛上生活小场景、猫与蝴蝶。
- `src/scene/IslandOcean.tsx`：自然水面、岸沫、码头、船与远处云雾。
- `src/scene/IslandScene.tsx`：光照、镜头、视差与标记投影。
- `src/App.tsx`、`src/model.css`：导航和模型查看器。

React、TypeScript、Vite、Three.js、React Three Fiber、drei、GSAP。
