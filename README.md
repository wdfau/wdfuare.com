# wdfuare.com

这个网站使用自己编写的 HTML 和 CSS，通过 GitHub Pages 免费发布。

- `index.html`：首页内容和样式。现在是一个测试欢迎页。
- `CNAME`：网站使用的域名 `wdfuare.com`。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。

修改 `index.html` 并提交到 `main` 分支后，GitHub Pages 会自动发布更新。

域名在 Name.com 管理和续费，网站代码保存在这个仓库中。

当前测试欢迎页设置了 `noindex`，正式内容准备好后可移除这个设置，让搜索引擎收录。
